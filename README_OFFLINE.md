# 妈祖 · 圣杯问心（离线 HTML 版）

文件：`mazu-offline.html`

使用方法：

1. 将 `mazu-offline.html` 发送到电脑或手机。
2. 电脑上双击文件，用浏览器打开。
3. 手机上可上传到任意静态空间，或通过文件管理器选择浏览器打开。

这个版本不依赖 OpenAI、VPN、服务器、npm 或外部图片。掷杯动画、文化内容和祈愿记录都在文件内；记录只保存于当前浏览器的本地存储。

如果要让其他人通过公网访问，需要把该文件上传到一个能从目标地区访问的静态网站服务或国内云存储静态网站托管。当前项目没有绑定国内云服务账号或域名，因此不会擅自替你选择和创建收费资源。
