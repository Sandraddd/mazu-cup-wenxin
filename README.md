# 妈祖 · 圣杯问心（iOS MVP）

当前主线是无需 Xcode 的离线网页版本：直接打开根目录 `mazu-offline.html` 即可体验。完整分享说明见 [`GITHUB_README.md`](./GITHUB_README.md)。

原生 SwiftUI iPhone 应用，围绕妈祖文化介绍、掷筊民俗体验与本地祈愿记录构建。

## 当前功能

- 首页与沉浸式深海氛围视觉
- 净心请示：称呼、问题、事项类别
- 起杯、旋转、落杯三阶段 SwiftUI 动画
- 圣杯、笑杯、阴杯三种随机结果与理性行动提示
- 本地祈愿记录（UserDefaults + Codable，不联网）
- 单条删除、二次确认后清空全部记录
- 妈祖文化、掷筊由来、杯象和礼仪内容
- 文化体验与非预测免责声明
- 支持系统“减少动态效果”；启用时跳过旋转与弹跳

## 打开与运行

1. 使用 Xcode 15 或更高版本打开 `MazuCup.xcodeproj`。
2. 选择任一 iPhone 模拟器。
3. 点击 Run。

最低系统版本为 iOS 17。项目暂未接入服务器、账号、付费、AI 或 AR。

## 素材策略

当前版本不使用外部或生成式图片，背景由 SwiftUI 原生绘制。后续确认合法授权素材后，可放入 `Assets.xcassets` 并替换 `AtmosphereBackground`。

## 开源参考

交互与工程设计参考了若干 MIT 授权的 SwiftUI 项目，但当前版本不引入第三方依赖、也没有复制第三方代码。详见 `OPEN_SOURCE_NOTICES.md`。

## 体验边界

应用结果由设备本地随机产生，仅作民俗文化体验，不代表神意，也不替代医疗、法律、财务或其他现实决策。
